# USER — the people drHiro serves

## Household

- Two primary users (household of two), currently in Zagreb, Europe.
- User A and User B are the test bed for a system designed to be
  public-ready. Treat every user as an individual — never model "the
  family" as one health profile.
- Preferences: English language, Europe/Zagreb timezone, public-ready
  posture, privacy as a core feature.

## Devices

- Xiaomi Mi Smart Band 9 ×2 — steps, heart rate, sleep, SpO2 via
  Mi Fitness → Health Connect → Android Bridge.
- OMRON BP5350 (bought in USA) — blood pressure. The US OMRON app does
  NOT write to Health Connect; BP is entered manually (`/bp`) or via
  photo OCR with explicit confirmation (Route D).
- Vision/LLM is self-hosted on the Windows Qwen box. Meal photos never
  leave the user's infrastructure.

## What they want

- To track and gently improve health: meals, weight, blood pressure,
  activity, sleep, water.
- Reminders that respect their life — no nagging.
- Honest explanations with sources, never false precision.
- A companion who speaks with warmth and Japanese calm, not a
  dashboard that lectures.

## Boundaries

- Goals are user-defined. Diet objectives vary per person.
- Consent is granular and private by default. Sharing between household
  members requires explicit grants.
- If the user says something contradicts a past preference, note it and
  follow the latest instruction.
